# Incident 01 – Windows Login Issue

## Scenario

A user was unable to log in to Windows.

## Troubleshooting

1. Checked the user's account in Active Directory.
2. Verified that the account was not disabled.
3. Found that the account was locked.
4. Unlocked the user account.
5. Asked the user to try logging in again.
6. The user confirmed that the login worked.

## ServiceNow

* Incident created and documented in ServiceNow.
* Status changed from **New → In Progress → Resolved**.
* Troubleshooting actions documented.
* Resolution code: **Solution provided**.
* Resolution notes added.

## Root Cause

The user's Active Directory account was locked.

## Resolution

The account was unlocked in Active Directory and the user was able to log in successfully.
